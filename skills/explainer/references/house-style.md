# House style

Josh's tuned settings and the look rules learnt so far. Use these values exactly unless Josh asks for a change.

## Finishing settings

| Setting | Value |
| --- | --- |
| Film grain | 15% overlay, 1.5px |
| Grain plates | Three plates in rotation at 12fps |
| Edge roughness | 5 |
| Halftone | 4px at 17% |
| Lens edge blur | 1.5 |
| Lens fringing | 2 |
| Lens barrel | 3.5 |
| Paper texture | Off |

Apply each finishing method as its own step. See [techniques.md](techniques.md).

## Look rules

### Shapes

- Build shapes as cut paper with sharp corners. Do not use smoothed splines or rounded curves where a cut edge would do.

### Light

- No glowing effects.
- Use dry highlights instead of glints or sparkles.
- Holes are crisp paper cut-outs, not glowing openings.

### Text and labels

- Prose and labels sit on solid panels. Never place text straight over a grid background.
- Do not let labels pop in abruptly. Reveal them with a stepped wipe.
